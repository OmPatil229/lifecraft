# LIFECRAFT

Turn your real life into a world you build.

## Overview
LIFECRAFT is a full-stack productivity RPG that converts real-world tasks into a living game world.

## Tech Stack
- Frontend: React + Vite + TypeScript
- Backend: Node.js + Express + TypeScript
- Database: MongoDB

## Setup Instructions

1. Clone the repository.
2. Run `npm install` in the root folder to install workspaces.
3. Copy `.env.example` to `apps/api/.env` and update the values.
4. Run `npm run dev` in the root folder to start both frontend and backend.

## Deployment
- Frontend: Vercel
- Backend: Render/Railway
- Database: MongoDB Atlas
